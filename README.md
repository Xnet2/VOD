# VOD חרדי

פיד וידאו אנכי בסגנון טיקטוק. האתר קורא ישירות את גיליון ה-`Videos` (אותה טבלה שתוסף "פלאש-פוש" ממלא מהגיזרה, אותנטי, הצ'אטים ופרוג), ומנגן את הסרטונים בגלילה אנכית.

## חיבור (פעם אחת)

1. בטבלה: **File ← Share ← Publish to web** ← בחר את הגיליון `Videos` ← פורמט **Comma-separated values (.csv)** ← **Publish**.
2. העתק את הקישור, והדבק אותו ב-`config.js` תחת `SHEET_CSV`.

זהו — האתר קורא את הטבלה בלי מפתח ובלי שרת ביניים. הלשוניות (הגיזרה / החתול השחור / פרוג / ...) נבנות אוטומטית לפי המקורות שיש בטבלה.

## איך זה עובד

- הקריאה מהמקורות (הגיזרה וכו') נעשית ע"י התוסף, שכבר דוחף הכול לטבלה.
- האתר רק קורא את ה-CSV, ממיין מהחדש לישן, ומנגן. אפשר גם להעביר קישור זמני דרך `?csv=...`.
- נתמכים גם קובצי `.mp4` ישירים וגם `.m3u8` (HLS).
